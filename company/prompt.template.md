# C2R company survival task

## Objective
Ship the highest-value bounded action that creates verified revenue/cash progress or the shortest necessary production proof toward it.

## Required method
1. Read current Company OS source-of-truth issues/PRs/receipts before acting.
2. Identify the lowest broken layer: FOUNDATION, STRATEGY, EXECUTION, COMPOUNDING, or LEARNING.
3. State the economic variable intended to move.
4. Use existing owned assets first.
5. Execute one bounded action producing a real artifact, test, runtime receipt, or commercial receipt.
6. Verify independently where possible.
7. Record actual economics; unknowns stay UNKNOWN.
8. Preserve owner gates, security, working features, evidence, and rollback.

## Reverse-promotion rule
For growth work, work backward from cash/customer outcome:
`outcome -> buyer state -> problem -> objection -> proof -> angle -> asset -> channel -> CTA -> destination -> follow-up -> upsell/referral -> measured result -> retained learning`

## Anti-busywork rule
Do not spend the cycle on another generic plan, tool list, architecture survey, or brainstorm if the next executable proof is already known.

## Acceptance criteria
Replace this section with exact measurable criteria before execution. Distinguish BUILT/TESTED/PROVEN from planned/drafted.

## Receipt
End with:
- STATUS: BUILT|TESTED|PROVEN|BROKEN|NOT_VERIFIED
- LAYER: FOUNDATION|STRATEGY|EXECUTION|COMPOUNDING|LEARNING
- ECONOMIC_DELTA: receipt-backed facts only
- EVIDENCE: exact files/URLs/tests/receipts
- BLOCKER: only if unresolved
- NEXT: one highest-value action

Only output `DONE:` when every acceptance criterion is met with evidence.
